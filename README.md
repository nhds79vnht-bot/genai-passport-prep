# くろ先生 生成AIパスポート対策

生成AIパスポート（2027年2月試験から適用のシラバスに照合した非公式問題集）の学習用SPAです。

## 実装済み

- 章別学習（各章10問ランダム）
- 60問模試（60分タイマー・各章12問抽出）
- 苦手分野ドリル（15問・ミス履歴から抽出）
- 単一選択 / 複数選択の採点
- 結果画面での解説レビュー
- 章別ミス率統計
- localStorageへの成績・統計保存
- 問題バンク1,500問（章300問×5章）
- 採点後の詳細解説（正解理由・誤答理由・参考書見返し章・ひっかけ）
- スマホ片手操作（1問表示・問題ジャンプ・未回答フィルタ）
- PWA対応（ホーム画面追加可能）

## 起動

```bash
npm install
npm run dev
```

## 問題データの保護

監査済みの問題データは `src/data/` の6ファイルに保存しています。旧仕様の自動生成スクリプトは通常の実行では停止し、既存問題を上書きしません。

## ビルド

```bash
npm run build
```

## くろ先生との連携学習

埋め込み画面では、従来のサーバー採点に対応する基本300問を初期設定にしています。チェックボックスで全1,500問の学習に切り替えられますが、追加問題を含む回の成績は端末内のみの保存です。連携先サーバーへの追加問題の採点・記録は別途サーバー対応が必要です。

GitHubへの反映と公開サイトのデプロイは別工程です。公開環境の反映はデプロイ状態を別途確認してください。

## 注意

- 問題はオリジナル作成の学習用です。
- 本番試験問題の転載は行わない方針です。
- GUGA公認ではない非公式の学習支援アプリです。
