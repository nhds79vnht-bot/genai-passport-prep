# くろ先生 生成AIパスポート対策

生成AIパスポート（第4版シラバス想定）の学習用SPAです。

## 実装済み

- 章別学習（各章10問ランダム）
- 60問模試（60分タイマー・各章12問抽出）
- 苦手分野ドリル（15問・ミス履歴から抽出）
- 単一選択 / 複数選択の採点
- 結果画面での解説レビュー
- 章別ミス率統計
- localStorageへの成績・統計保存
- 問題バンク300問（章60問×5章）
- 採点後の詳細解説（正解理由・誤答理由・参考書見返し章・ひっかけ）
- スマホ片手操作（1問表示・問題ジャンプ・未回答フィルタ）
- PWA対応（ホーム画面追加可能）

## 起動

```bash
npm install
npm run dev
```

## 問題バンク再生成

```bash
npm run generate:questions
```

## ビルド

```bash
npm run build
```

## 注意

- 問題はオリジナル作成の学習用です。
- 本番試験問題の転載は行わない方針です。
- GUGA公認ではない非公式の学習支援アプリです。
