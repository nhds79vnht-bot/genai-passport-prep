# 2027年版 生成AIパスポート問題集：第2〜5章 引き継ぎ手順

## 目的
各章300問を2027年2月適用のGUGA公式シラバスの中項目・小項目に照合し、重複・範囲外・誤答を修正または差し替え、合格に資する分布へ再設計する。単に300問の数合わせをしない。各章は独立して監査し、まとめて報告する。GitHub Actionsは使わない。

リポジトリ：nhds79vnht-bot/genai-passport-prep
対象：src/data/questionBank.ts（全章各60問）、syllabus2027Questions.ts（全57問）、expansion2027Questions.ts（全100問）、advanced2027Questions.ts（全100問）、practice2027Questions.ts（全100問）、applied2027Questions.ts（全843問）。

## 抽出方法（重要：途中で数が欠けた失敗を繰り返さない）
1. GitHubから6ファイルを全文取得する。先頭90行などの部分取得だけで集計しない。
2. questionBank.tsはQuestionオブジェクトの id/chapter/topic/prompt/choices/answers/explanation を読む。IDは q001 等。
3. 残り5ファイルは rows または items 配列の各行を読む。行番号は「対象章の出現順」ではなく、**配列全体の0始まりindex+1**。IDの接頭辞は sy27 / ex27 / adv27 / pr27 / ap27。3桁ゼロ埋め。別章を飛ばして採番し直すと実際のIDと食い違う。
4. 文字列は単一引用符・二重引用符・エスケープ・改行が混在しうる。単純な正規表現だけで全件取得できたと判断しない。可能ならTypeScriptパーサーまたはソースを安全に評価しない静的ASTで読み取る。正規表現を使う場合は件数・ID・章の連続性を必ず独立検証。
5. 6ファイルから全1500件、対象章300件、対象章のID重複0件を確認。各ファイル別の対象章件数も報告。数が一致しなければ分類に進まず抽出方法を修正する。
6. 既存topicは分類候補にすぎない。本文・正答・解説を見て新シラバスの中項目と**小項目**を判定。別章に属する内容や判断不能な問題は「要確認」とし、無理に振り分けない。

## 公式照合と品質判定
- 2027年2月適用のGUGA公式シラバスを一次資料で確認。旧2026年版PDFを誤って使わない。取得できない小項目は未確認と明示する。
- 各問題に source_file, id, old_topic, new_section, new_subsection, decision(KEEP/REVISE/REPLACE/MOVE/HOLD), reason を付す。
- 選択肢と正答の一致、説明の正確性、選択肢の紛らわしさ、同義反復、難度、範囲内かを監査。
- 第3章のGraph RAG / Agentic RAG / MCP / Function Calling / コンテキストエンジニアリング、第4章のシャドーAI / プロンプトインジェクション / C2PA / 出力採否などは、公式詳細項目を確認して適切に扱う。単に流行語を追加するだけでは不十分。
- 出題比率は公式比率と混同しない。学習上の重要度に基づく暫定配分案を作り、小項目の欠落・偏りを解消する。範囲外・重複を差し替え、単なるtopic書換えで数合わせしない。

## 作業と報告
- 章ごとに300問の抽出→全件小項目割当→重複/誤答監査→必要な修正・差し替え→再集計→保存→再読込検証を一続きで行う。
- 10問/20問ごとの承認依頼・細切れ報告はしない。作業が止まる場合は実施済み範囲と未完了を明示。
- 本番問題ファイルを変更する場合は変更前のblob SHAを取得し、差分とID一意性・300問維持・正答整合を確認。保存後に再取得して検証する。
- GitHub Actionsは使わない。
- 完了報告には章別・小項目別の旧→新件数、KEEP/REVISE/REPLACE件数、重複除去件数、問題ID台帳、コミットSHA、未解決事項を含める。未実施を完了と書かない。
